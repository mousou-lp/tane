# 妄想のタネ

未来のことと自分の偏愛をかけあわせて、架空のサービスを考えるのを手伝うページです。https://mousou-lp.github.io/tane/ に出ています。

妄想LPのモットーは、次のとおりです。

> 未来の技術と自分の偏愛から、架空のサービスを妄想する。その未来を考えることで、いまの自分の生き方に干渉して、ポジティブな変化を起こす。

このページは、そのかけあわせるところを手伝います。

遊び場なので、だれが足しても直してもかまいません。mainに入ると、数分で自動で公開されます。

## できること

1. **未来を選ぶ**: [未来のこと](https://mousou-lp.github.io/mirai/)に並んでいる未来から1つ選ぶ。ランダムでも選べる
2. **偏愛を書く**: 自分がつい時間を使ってしまうものを1つ書く
3. **かけあわせて妄想する**: 次の3つが出てくる
   - 考えるための問い。偏愛を当てはめた問いと、その未来の「妄想のタネ」
   - AIに貼るための文。ChatGPTやClaudeなど、ふだん使っているAIに貼ると、サービスの案と、いまの自分が明日からやれる小さなことを出してくれる
   - LPのリクエストの用紙。思いついたサービスを書いて押すと、[ポータル](https://mousou-lp.github.io/)のリクエストの用紙が、中身の入った状態で開く

入れたものは、その端末のブラウザの中（localStorage）にだけ残ります。どこにも送りません。AIのAPIも使っていないので、お金はかかりません。

## 直すところ

- **問いを足す・変える**: `public/app.js`の`QUESTIONS`に1行足します。`{love}`のところに、書いた偏愛が入ります。どの未来にも合う問いにします
- **未来を足す**: ここではなく[mirai](https://github.com/mousou-lp/mirai)に足します。未来のことの`futures.json`を読んでいるので、足すと自動でここにも出ます
- **AIに貼る文を変える**: `public/app.js`の`promptFor`です
- **偏愛の例を変える**: `public/index.html`の`data-hint`のボタンです

## 手元で見る

```bash
python3 -m http.server 5182 -d public
```

ビルドはありません。`public/`の中身が、そのまま公開されます。未来の一覧は公開中の`https://mousou-lp.github.io/mirai/futures.json`から読むので、手元で見るときもネットにつながっている必要があります。

## しくみ

- `public/index.html`、`public/app.js`、`public/style.css`だけでできています。入れるものはありません
- 色・余白・文字の大きさは、ポータルと同じ値を使っています
- 公開は`.github/workflows/pages.yml`が、GitHub Pagesに出します
- 検索エンジンには載りません。ポータルの`robots.txt`が、`/tane/`もまとめて止めています
